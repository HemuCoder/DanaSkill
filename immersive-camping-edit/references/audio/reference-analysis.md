## 推导到本 Skill 的选择

1. **把配乐安排成有明确作用的小段落。** 坐下享用、压缩相近步骤、轻松插曲、时间变化、收束离开都可能成立。连续原声是完整的段落选择。
2. **先写退出理由，再铺音乐。** 下一项关键操作、对白或环境声值得观众注意时，让音乐完成它的任务并退出。音乐的停止本身也改变观看注意力。
3. **一段音乐跨多个镜头，镜头仍服从动作。** 参考样本的候选音乐段从几十秒到数分钟都有，不能由单镜长度或固定卡点决定是否换歌。
4. **把差异留给当期素材。** 三位作者的同类事件有不同处理；本用户偏好的舒缓、简洁选曲是项目方向，具体增益和淡化范围需在本期音源上试调。
