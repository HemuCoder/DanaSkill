# 剪辑与调色交接

用户采用“Codex 剪辑 → 人工修改 → Codex 调色 → 人工微调导出”的流程时，分两次交接。用户要求首次交付带调色时，在初始工程交付前按 [调色流程](color-grade.md) 验证并写入视频片段自身的原生调整参数；人工修改后的第二次交接仍以最新工程为准。

## 第一次交接：可编辑粗剪

完成全片剪辑、原声与独立字幕，交付在本机验证过的剪映工程和审片 MP4，记录工程位置。默认保持 4:3。用户在剪映修改素材、片段、字幕、音频、特效和构图；收到“已保存，开始调色”之类的明确指令后进入第二阶段。

在本期目录保存一个 `handoff.json`，记录工程及主时间线 ID、剪映版本、工程位置、交接快照、时间线哈希、当前阶段和已验证能力。已有素材映射与原生片段 ID 可直接复用，无需另建数据库。

## 第二次交接：以最新工程为准

1. 通过目标版本实际支持的读取或导出入口取得用户最新保存工程，保留快照。确认当前主时间线和外部素材均可读取。应用正在保存时等其完成，避免取得一半旧、一半新的文件。用户明确确认剪辑未改并要求按原交付基线继续时，可在核对基线并完整备份当前工程后据此处理；记录该依据，保持最新编码工程回读能力的独立状态。
2. 把最新工程作为剪辑依据，仅处理逐镜颜色与细节增强。保留人工调整的时序、字幕、特效、音频、构图和既有颜色对象。旧 `timeline.json`、FCPXML 和补充草稿仅作历史快照，不能据此重建并覆盖用户工程。
3. 从最新时间线生成本轮镜头映射，重新检查入选画面并生成 [调色方案](color-grade.md)。优先用原生 segment ID 匹配，同时核对素材身份和源区间；分割、复制或替换过的镜头按新画面复核。`clip_index` 仅供本轮快照定位，排序变化后重新生成。
4. 旧方案的时间线哈希失效时，保留原方案，生成下一版。可复用已确认匹配镜头的起始参数，再检查变化部分；不能只替换哈希让旧参数通过校验。
5. 通过已验证的批量入口更新目标视频片段自身的原生调整参数。检查既有颜色调整，记录目标 segment ID、原参数与本轮写入字段；后续修订先核对最新值，保留用户其他修改。用户明确要求独立调节轨道时再按该方式处理，并核对多轨作用范围。
6. 核对结构、代表片段实际画面，保存、退出并重开验证；通过后交给用户复核颜色，阶段改为 `awaiting_user_color_review`。按 [风格验收](color-grade.md#风格校准与验收) 单独记录视觉目标的完成情况。另选中片段核对原生面板值，手工改值保存单独验证，逐项记录检查范围；阶段变化只表示工程已交用户复核。

交接记录的最简形式：

```json
{
  "version": 1,
  "stage": "awaiting_user_edit",
  "project": {"path": "本机工程目录", "id": "工程ID", "main_timeline_id": "主时间线ID", "app_version": "实际版本"},
  "snapshot": {"path": "交接快照", "sha256": "快照哈希", "captured_at": "时间", "readable": true},
  "timeline_sha256": "当前可读取时间线的哈希",
  "grading": {"plan": null, "native_status": "not_applied", "style_status": "pending", "written_segment_ids": [], "checks": {"image": "unverified", "panel_readback": "unverified", "manual_edit_save": "unverified", "reopen": "unverified"}},
  "capabilities": {"initial_segment_color_write": "unverified", "latest_project_readback": "unverified", "latest_segment_color_write": "unverified"}
}
```

阶段使用 `awaiting_user_edit`、`ready_for_grade`、`awaiting_user_color_review`。颜色预览 MP4 与原生工程分别记录成果，避免一个状态掩盖另一个。

## 当前可验证的范围

本机 Mac 剪映 11.6.0 的本期 v6 已配置 83 个视频片段、747 个九类原生效果材料，八个代表帧静态复核无明显异常。主工程已保存退出并重开，C1370 九项原生面板值再次读回，日间及手部代表画面保持，工程留给用户审核，阶段为 `awaiting_user_color_review`，风格尚待用户批准。GUI 手工改值保存和所有镜头完整面板读回尚未全面验证；本轮未导出，未连续播放全片或听审。本次用户明确确认剪辑未改，故据原交付基线继续；最新编码工程的正式回读及人工改稿回写通路仍未打通，不能将本次应用扩展为任意改稿均可回读。各路径实测见 [调色](color-grade.md#本机验证边界)；工程保全见 [剪映工程](jianying-project.md)。

最新结构无法取得时保留用户保存的工程，将阶段保持为 `ready_for_grade` 并记录具体缺口。历史时间线可继续渲染该历史版本的调色 MP4，不能声称已包含用户的新修改。烘焙成片或替换调色代理也不能标记为“原生片段调色完成”。
