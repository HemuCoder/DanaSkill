# 风格与剪辑判断

## 观看目标

让观众与人物一起进入环境、安顿生活、感受使用和享用的时刻。保持旁观的距离和真实的生活速度，让动作、触感、空间与人物关系逐步被感知。

风格由以下关系共同建立：整体画面使人知道身在何处，细节让人感到正在做事，结果和使用使准备有意义，安静停留让人有时间体会。日记旁注带出这次选择与人物语气，连续原声让环境保持在场。

默认交付画幅为 4:3，片头和简介采用 Montserrat 白字，正文采用系统字体白字黑底；所有文字按本文件的剪映面板规格与渐显隐时长执行。用户指定其他画幅或样式时按其要求执行，并保全动作和阅读空间。

每期依素材确定人数、季节、地点、设备、饮食、是否过夜和时长。围绕已拍到的小过程组织完整体验；阶段数量和镜头长度服从本期内容。

## 镜头语法

### 先确定镜头的作用

| 作用 | 观众获得什么 | 保留与退出的依据 |
| --- | --- | --- |
| 建立空间 | 人在哪里、物件如何分布、动作朝哪里发生 | 留到主体与关系可辨认，新的行动出现后推进 |
| 推进事件 | 状态如何改变、关键操作如何完成 | 保留理解变化所需的触发、执行与结果 |
| 呈现细节 | 手的用力、材质、声音与微小变化 | 留到该细节可感知，并接回所属事件 |
| 呈现结果与享用 | 准备带来了什么、人物如何使用它 | 给成品、使用或人物反应以辨认和感受时间 |
| 安静停留 | 空间、光线、环境声或关系本身的感受 | 允许持续观看；同类镜头重复时压缩，新的细微变化可延长 |

一个区间可兼有多个作用。素材提供多个景别时，主动组织远景、中景、近景和特写的变化：远景建立环境，中景看人物做事，近景与特写感受操作和材质，再回到整体或结果。按动作和注意力选择切换位置，保持人物方位、运动方向与动作阶段可理解。

按源时间区间识别事件，检查全条素材中的主体入场、操作变化与结果。首段空景之后可能出现关键行动，先定位实际变化再选区间。为主要事件标出开始状态、关键执行和完成状态；相机连续拍到的过程可以在一个稳定镜头内成立。

先用整体交代人物和空间，再按需要靠近关键操作，回到完成状态或使用。缺少某个景别时使用已有画面讲清关系；减少无作用的切换。自然做事的手、背影、人与环境的比例和同伴互动都可承担叙事。

### 重复补录与镜头衔接

先按同一事件、物件和动作阶段把素材归组，再识别不同拍次与景别。拍摄时间用于定位；重复补录可以提供同一动作的不同视角，按画面中的状态选择互补区间。

优先用中远景的动作起势接近景执行，再用特写细节或完成状态接回整体。切点检查手的位置、工具方向、物件开合与数量、人物朝向、光线和动作速度，让前一镜的变化在后一镜继续。已经完成的动作在后镜保持完成状态，正文同一过程中的重复起势和完成只保留一次；片头高光可提前展示正文中的精彩片段。

相似机位连续切换容易显得跳动，优先换有明显景别或角度变化的补录。状态无法匹配时采用已有的细节、环境或人物反应交代省略，或保留完整单镜；后续状态仍须成立。对话保持完整话轮，关键操作声贴合可见动作，环境声可连接相邻镜头。声音桥以实际工具支持和连续听审为准。

在选镜记录中保留事件组、拍次、景别、动作阶段和匹配依据，在剪辑记录中说明主要剪口的联系。镜头丰富性来自互补的观看信息，景别顺序和数量随素材调整。

### 环境空镜与段落呼吸

在部分操作之间，让观众从手上的事抬头感受周围。使用本期真实拍到的树影、水面、风吹帐布、光线、天气或营地环境；空镜可以承接等待、短暂休息、阶段完成与时段变化，也可以让一段值得听的环境声独立展开。

进入空镜前找一个自然停顿或注意力转移，离开时接回同一件事的进展或下一件事。用同地点的光线、物件、视线或声音把“前一动作 → 环境停留 → 后续动作”连接起来。关键操作先让人看懂，空镜中的细微变化和声音得到感知后再返回人物。

按段落的紧松安排空镜。连续操作较密时留一口气，已经有充分静坐或环境停留的段落保持简洁。长度取决于可感受的光影、运动和声音，使用频率随本期素材与节奏决定。空镜承担空间、感受或时间关系，选入时记录具体作用；位置、天气和光线须与前后镜头相容。

检查候选源区间确实没有主线动作正在发生；同一文件后半段出现人物或车辆时，分别记录空镜和行动区间。原声可跨剪口延续以维持在场感，新增声音保持真实来源并实际听审。

### 处理素材不足与冲突

稳定观察是选镜条件，连续检查方法见 [稳定性筛选](review.md#稳定性筛选与验收)。平顺且有目的的运镜可以保留；抖动优先通过替换、修剪或已验证的防抖处理，最终动作和构图都要成立。

当完整性与重复冲突时，保留新信息、关键变化和结果，压缩已被理解的重复操作。当漂亮画面与连贯性冲突时，找到它承担的空间或感受作用，再决定位置和长度。片长从这些选择中形成。

缺少事件结果时，先寻找同一事件的完成状态、后续使用或能接通的动作；信息足以理解时缩短该段，仍无法理解时合并或省略。缺少享用镜头时使用确实拍到的完成状态和环境停留，保持人物行为与时间关系真实。

## 节奏

### 决定入出点

进入时让观众知道要看什么，关键变化发生时保持动作可读，离开前给结果以辨认时间。快动作可能需要更完整地保留，重复慢动作可以省略；按内容调整，采用正常速度检查。

切点由下一镜增加的信息和当前镜头尚需完成的体验共同决定。结果刚出现就切走会使劳动没有落点；同一信息反复展示会使过程停滞。按事件复看，检查每次切换是否在观众能跟上的位置。

### 组织段落的呼吸

在关键操作段落集中注意力，在使用、互动与环境段落释放注意力。连续原声和无字画面为真实声音、动作及安静停留提供空间。舒缓来自有余地的观看，镜头仍应持续提供可理解或可感受的内容。

重复步骤可用有因果关系的省略或蒙太奇串联，保留重要操作的真实速度。音乐可以跨镜头连接一个段落；动作完整性优先于卡拍。

### 开场与结尾

先剪正文，再选取本期有区别的操作、享用、互动和环境片段组成高光，固定放在全片最前面。高光展示有吸引力且可理解的瞬间，景别和体验互补，长度随内容确定。整段高光上居中显示 `IN THIS EPISODE...`，随后转入正文与前部中英简介。高光和正文均引用完整原片的相应区间，保留人工修改余量。

结尾放在本片已成立的状态。坐下享用、安静相处或完成离开都可收束，保留足以感受结束的画面和声音尾部。素材只覆盖半天时围绕半天的变化完成小篇章。

## 时段衔接

先建立前后事件关系，再选择直切、声音桥或短暂淡变。以空间、光线和生活动作交代时间变化。

| 变化 | 寻找的联系 | 素材有限时 |
| --- | --- | --- |
| 进入场景 | 环境、主体入场、停下和开始做事 | 从第一个可理解的真实动作进入 |
| 环境或光线改变 | 同地点或同物件保持联系，新的光线与行动接续 | 用已有新时段宽景重新定位，再进入活动 |
| 经过较长时间 | 前一活动收束，同地点重现，下一活动开始 | 保留真实时间跳跃，必要时加入有依据的简短时间信息 |

按素材实际覆盖的变化规划，保留昼夜差异和人物位置的可理解性。需要停顿时使用短暂淡变或黑场，正在发生的生活通常直接接续。

声音桥使用前后场景真实可用的录音，让观众先听见新空间或短暂延续上一段声底；连续听审后确定位置与长度。随附基础渲染器的逐段淡化只完成其声明的能力，J/L cut 需在实际支持的工具中实现。

在 `edit-notes.md` 用“前镜 → 联系线索 → 后镜”记录重要边界，连续复看两侧约 10–15 秒，检查动作、位置、光线与声音是否容易理解。

## 颜色和光线

采用韩系 Ins 的简约、干净、通透感。白色干净并保留受光暖意，肤色自然；亮部柔和有细节，主体暗部清楚且黑位有支撑；绿色与杂色克制，材质清晰、整体层次轻柔。保留日照方向、傍晚暖意、夜间灯光与暗部关系，让不同时间仍呈现真实差别。

先做正确的色彩转换，再校正和匹配相邻镜头；原生参数与效果按 [逐镜头调色](color-grade.md) 执行。依据本期画面调节力度，先在目标引擎校准代表镜头，再逐镜应用。

## 实拍中的片头与信息介绍

### 高光与中英简介

全片从主轨道上的高光剪辑开始。建立覆盖整个高光区间的独立文字对象，文本严格为 `IN THIS EPISODE...`，保留大写与三个英文句点。文字块在画面水平、垂直方向均居中；切换底片时保持位置与显隐连续。根据亮暗变化调节柔和阴影，保持整段可读。

高光之后，在正文前部实拍上安排中英简介，交代本期主题、营地/地点以及确有需要的天气或当次条件。每个信息组同时有中文和对应英文；主题在一个镜头建立，地点及条件可在随后镜头展开。按信息层次与画面空位排布，不挤在同一帧。

先检查用户消息、素材记录与已核实现场信息。主题可从本期真实事件概括；营地/地点称谓和拟展示的天气缺少必要依据时，集中向用户询问。准确日期、温度等只有纳入简介时才需要相应事实；用户明确选择泛称或省去某项时据此处理。等待回复期间继续素材导入、选镜与正文，所缺介绍项保留待确认状态，完成信息后再交付完整片头。英文是已确认信息的自然翻译，保留地点专名的准确性。

### 排版与可读性

用整齐对齐、稳定版位、充足留白和克制层级呈现精致感。主题可在 40–55% 缩放范围内相对突出，地点与天气组采用较小缩放；字号保持 10。中文与英文分行、间距一致；每次突出一个信息组，版位避开人物、手部和动作结果。介绍文字使用透明底与柔和阴影，正文字幕使用规定黑底。

高光固定居中，其余简介按连续镜头中的安静区域选择统一锚点。亮背景先检查阴影的不透明度、模糊度和字形边缘，增强可读性后复看暗画面，保留柔和轻盈的外观；每组记录最终参数。只有透明度变化参与文字动画，文字位置与缩放在出现期间保持静态。

[编辑规格模板](../assets/intro-kit/presets.json) 保存剪映面板目标、文字角色和必备模块。填写本期内容、独立对象 ID、源依据和时间线区间后写入 `intro-plan.json`。模板按剪映界面单位描述意图，原生内部字段以当前版本实际保存的对象为依据。

## 统一文字规格

下表数值是剪映文字面板的目标值。字号、缩放和背景百分比分别设置；背景高度、宽度与圆角按其对应控件填写，保持与画布尺寸分离。

| 属性 | 高光、片头及简介文字 | 正文日记文案 |
| --- | --- | --- |
| 字体 | Montserrat，常规字重；检查本期所有字符覆盖 | 系统中文常规字体，macOS 默认 PingFang SC Regular |
| 字号 | 10 | 10 |
| 缩放 | 40–55%，按层级与构图选定 | 40% |
| 文字颜色 | 白色 | 白色 |
| 背景 | 透明 | 黑色，不透明度 65% |
| 背景圆角 | 不适用 | 6% |
| 背景高度 | 不适用 | 10% |
| 背景宽度 | 不适用 | 15% |
| 阴影 | 开启柔和阴影，按实际亮暗画面调整不透明度与模糊度 | 以黑底保证对比度 |
| 位置 | 高光文字水平垂直居中；中英简介统一对齐、避开主体 | 底部安全区水平居中，避让手部与动作结果 |
| 入场 | 渐显 0.8 秒 | 渐显 0.8 秒 |
| 出场 | 渐隐 0.5 秒 | 渐隐 0.5 秒 |

先核对 Montserrat 是否实际可用、英文标点和中文是否缺字。Montserrat 用于英文与可覆盖字符；中文缺字时使用系统中文常规字体补齐字形，并记录实际字体分工。缺少 Montserrat 时先通过可用字体来源准备字体或向用户索取，相关标题保留待完成，其他剪辑继续。

所有文案，包括物件注释、对话字幕和结尾文字，统一使用独立渐显 0.8 秒与渐隐 0.5 秒。显示时长须容纳这 1.3 秒动画及完整阅读时间；短句与剪口冲突时延长文字跨镜停留或调整文案和时序。跨镜延续同一文字对象，仅在首次入场与最终离场各执行一次动画。文字及其黑底一起显隐，底片和原声继续正常播放。

在剪映中先制作亮背景、暗背景及正文代表文字，读回字号、缩放、背景、阴影与动画时长；连续播放并保存重开后复查。按 [原生文字实现](jianying-project.md#字幕样式补全) 从已验证对象批量应用。内部参数转换须由实际保存结果和面板读回确认，辅助渲染器的像素比例仅用于诊断。

## 字幕与文案

正文沿用统一文字规格，一行优先、最多两行。按完整意思改写或分时出现，保留必要因果和人物语气；字数由规定样式下的真实可读宽度决定。发生遮挡时先调整出现时段或精简文案，再把同一段字幕统一移到安全位置，保留规定字号、缩放及背景参数。

### 有人在场的日记旁注

让观众跟上这次露营，也逐渐认识做事的人。语气朴素、亲近，围绕当次具体的人、物件和变化表达；保留自然的口语、偏好和轻微幽默。把普通动作写成宏大感悟、套用“逃离喧嚣、治愈一切、人间值得、奔赴热爱”等口号，会抹掉这一次的特点。

**事实有依据，并且对理解、人物或叙事至少有一种作用，句子就有保留价值。**

| 作用 | 值得交代的内容 |
| --- | --- |
| 理解 | 当次情境、选择理由、物件用途、过程中的小状况 |
| 人物 | 有依据的偏好、使用习惯、身体感受、伙伴互动与轻幽默 |
| 叙事 | 本次安排的铺垫、行动变化、阶段完成、下一步与前后呼应 |

画面中已经出现的动作和状态，也能承担阶段收束或人物表达。“桌子安顿好了，接着准备晚饭”可以连接搭建和做饭；逐个报告桌子、杯子、餐具都已摆好，则缺少推进。结合前后事件判断作用，保留能让观众跟上生活的句子。

个人经历、过去使用习惯、打算、心情及冷暖、味道等主观感受，来自用户陈述或可核实的现场人声。画面支持的当前行为、关系和变化可以写成自然观察；仅有蒸汽不能确认香味，添衣也不能独自证明本人觉得冷。轻幽默贴着可见行为，不替人物或动物编造内心独白。缺少某类依据时，使用有依据的表达或让该处留白。

### 按事件安排疏密

建立事件链时，先找本期值得交代的情境、人物与变化，再写候选句并删去赘述。开场让观众进入这一次，正文在选择、变化和阶段完成时接上人物的声音；重复操作、完整动作和安静享用可形成连续无字段落。按事件安排内容，不设每分钟句数或字幕总量，也不要求每个事件都配字。

按前后事件连接句意。自然的两句可构成一个小段落，中间按意思换气；一句可跨相邻镜头保持，按整段阅读检查。保留完整意思和人物语气，跨剪口连续显示同一句。

每句停留包含渐显 0.8 秒、完整可读的保持时间和渐隐 0.5 秒；长句和两句小段落按阅读量延长或分时出现。读完后留出无字观看空间，检查连着读是否疲劳，以及长段留白是否遗漏本次选择、关键变化或人物表达。先利用现有信息补足理解，再判断该处是否适合安静观看；用户明确要求纯观察时遵从其要求。

在 `edit-notes.md` 的字幕表保留成片入出点、文案、作用、事实依据与前后关系，并记录主要连续留白段落的作用。缺少某条依据时只处理相关内容，继续规划其他有价值的旁注。字体样张用标明演示用途的文字，占位文字不进入正式字幕表。
