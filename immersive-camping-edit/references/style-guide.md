## 镜头语法

使用稳定中远景交代场地、人物和动作；近景呈现手部、器具和食物；回到完成状态或人物使用。改变景别时保持动作因果与空间方向可理解。

按**源时间区间**判断镜头作用。同一个稻田镜头可以先交代环境，再出现车辆驶入；整条素材只贴“空镜”会丢失到达事件。先查整条素材中的主体入场、转向、停车、人物离车等变化，再记录各候选入出点。对承担主线的动作，在选镜记录中标出起因、关键执行与结果对应的源时间，剪短后仍要让观众看懂。

车辆入场示例：短暂环境引入 → 车辆进入并沿道路行驶 → 停车或下车 → 取装备。素材不必覆盖每一步；使用实际拍到的线索，维持地点与行动的关系。风景开始几秒无人时，要继续查后半段。已经确认拍到且承担叙事的入场动作，应先找到可辨识的稳定区间，再考虑纯景物插片。

稳定观察是选镜条件，按 [稳定性筛选](review.md#稳定性筛选与验收) 连续检查完整拟用区间；平顺有目的的运镜可以保留，明显手抖、碰机位和启停晃动先替换或修剪。接触表只支持内容判断，不证明运动稳定。

参考实例：

- 03:28–04:12：打开操作台 → 冰块和倒饮料 → 成品杯 → 人物喝下去。
- 07:12–07:33：桌架整体操作 → 手部卡扣 → 成型桌架 → 安装透明桌板。
- 12:18–13:09：煎吐司和打蛋 → 装盘、倒饮料 → 早餐成品 → 两人用餐全景。

人物注视正在做的事、同伴和环境。手、背影、人与营地的比例关系都能承担叙事。车内、帐内望外和手部视角可以与旁观视角配合。

用树干、车身、天幕、帐篷入口建立前后层次。4:3 有利于同时容纳树木高度、全身动作和地面操作。画幅选择先保住关键内容，再追求参考外观。

## 节奏

参考预告切点间隔大多约 1.6–1.8 秒。正文自动粗检的候选镜头时长中位数约 5–6 秒，很多位于 4–8 秒，也有十几秒的操作过程。自动检测会受相似机位、运动和淡出影响，这些只是初始参考。

让动作决定切点。在动作结果尚未可读时继续保留，在重复阶段用另一个有信息的镜头推进。任务完成后用成品、享用或环境镜头消化段落。

场景内以直接切换为主。原 LI300 参考约 08:33 入夜、11:24 清晨用压暗/黑场分章；这两处对应短暂数字静音。这属于该片的选择，新片按下节建立时段关系后决定是否需要停顿。

## 时段衔接

先把前后事件接通，再决定直切、声音桥或短暂淡变。默认以动作和环境推进，开场、入夜、第二天不自动生成黑场、居中大字或花哨转场。

| 节点 | 优先寻找的关系 | 素材不足时 |
| --- | --- | --- |
| 开场 | 环境与人物/车辆到达 → 停下 → 开始布置 | 以实际第一个完整动作进入；可省预告与标题卡 |
| 入夜 | 正在做的事 → 同营地渐暗/灯亮 → 继续操作与享用 | 用已有晚间营地重新定位后进入夜间活动；保留真实时间跳跃 |
| 次晨 | 当晚活动收束 → 已拍到的时间线索 → 同地点白天重现 → 起身/出帐/晨间操作 | 用真实夜间尾镜与晨间首镜建立关系，必要时一句简短事实标签 |

同一车辆、帐篷、桌面或视线方向可维持空间。让宽景提供时间与地点，近景承担动作，结果镜头给段落落点。缺少黄昏就使用确实拍到的夜景；缺少睡觉就以已有夜间活动收尾；天气、日出和熄灯都须有证据。

有合适原声且工具支持时，可用下一镜真实环境声提前进入，或让上一镜声底短暂延续，连续听审后确定长度。不能把随附渲染器的逐段淡入淡出写成已实现的 J/L cut。黑场与章节字只在明确需要停顿或用户指定时使用，剪完检查它是否打断正在发生的生活。

在 `edit-notes.md` 用“前镜 → 时间/空间线索 → 后镜”记录本片实际存在的到达、入夜与次晨。按成片时间连续复看各边界前后约 10–15 秒，检查人物位置、动作阶段、光线和声底是否能被理解。

## 颜色和光线

白天保留树木绿色、米白帐篷、灰地面与浅色车身；傍晚保留金色光；夜间突出暖灯生活区，保留树林暗部；清晨恢复自然光与树影。

先做正确色彩转换，再匹配相邻镜头曝光、白平衡和肤色。保持有意义的日夜差异。原片不足以确定 LUT、白平衡数值、拍摄设备或变速倍率。

## 字幕与文案

### 统一排版规格

中文日记正文固定为以下起始规格，先做实际画面样张再微调。查看 [自有素材排版样张](../assets/caption-layout-reference.jpg)，该图仅演示文字外观。

| 属性 | 默认目标 |
| --- | --- |
| 字体 | 常规或细字重的现代中文无衬线；同一期固定一个家族、一个正文字重 |
| 字体选择 | macOS 优先苹方常规或黑体细体；其他系统可用思源黑体/Noto Sans CJK Regular、微软雅黑常规。按实际字形检查并记录替代字体 |
| 字号 | 画面高度约 2.4%，1440×1080 时约 26 px；720×540 时约 13 px。高分辨率按比例放大 |
| 颜色与底色 | 白字，黑色底约 53% 不透明度；每行贴合字宽，横内边距约 0.35 字高、纵约 0.16 字高 |
| 位置 | 默认水平居中，黑底下沿距画面底部约 9% 高度；同一段落保持一致 |
| 行长 | 一行优先，通常 8–18 个中文字；最多两行，文字最大宽度约画面 72%。长句先改写或分时出现 |
| 动效 | 默认静态出现和消失，必要时轻淡入淡出；保留平静观看节奏 |

不透明度 53% 等价于约 47% 透明度，按软件字段含义填写。原生剪映字号、背景宽高、坐标与像素的单位不同，须按 [原生文字样式](jianying-project.md#字幕样式补全) 用实际画面校准，不能照抄 26 作为所有软件的字号。渲染器规格与原生工程分别验收。

避开花体、衬线正文、粗描边、重阴影、彩色字、弹跳与打字机效果。英文信息标签用同一简洁无衬线体系、少量大写、白字透明底，字号约 2.8% 高度；只交代有证据的信息，通常一行。英文标题与中文旁注分工清楚，不每个时段都叠一套中英标题。

字体可以按本机资源替换，固定记录实际家族、字重和字体路径；公共 Skill 不打包系统商业字体。新电脑须检查中文标点、拉丁字母及缺字，按最终画面测量大小与留白。正文既要克制，也须在目标观看尺寸可读。

字幕避让人物脸、手部操作、食物和器具结果。优先挪开字幕出现的时段、缩短文案，仍遮挡时将整组同场字幕移到另一处安静留白；保持安全区和统一对齐，不让每句话随机跳位置。随附渲染器仅支持 top/center/bottom，复杂避让在剪映独立文字对象中完成。全片交付前检查日间、手部、夜间、两行文字和首中末字幕。

### 具体自然的旁注

先决定这句话提供什么，再写文字。允许补充当次选择的理由、可证实的小状况、具体物件的使用体验、自然的个人体会与轻微幽默。个人经历、打算和心情来自用户陈述或可核实的人声；画面只足以支持可见事实时，按事实写或留白。

每句过两道检查：**事实是否有依据，文字是否增加了画面之外的理解。** 两者都成立才用。先以无旁注剪辑为基线，发现确有必要补充的信息再加字。“桌子搭好了”“杯子也摆好了”“倒出的水冒着热气”即使属实，通常仍是重复画面，应删去。克制的观察可以成立，但不能为了让句子显得具体而逐镜报动作。

每句必须指向这次露营里的一个具体对象或细节。画面已讲清的拿起、打开、放下通常无需逐步解说。去掉能无差别贴到任何旅行片的口号，以及“逃离喧嚣、治愈一切、人间值得、奔赴热爱”等套话；也别将普通动作写成宏大感悟。

原创假设例子，仅说明写法，须有对应证据才能使用：

| 可见/已知依据 | 可考虑的旁注 | 使用判断 |
| --- | --- | --- |
| 车辆通过稻田到达已确认的营地 | 过了这片稻田，就到营地了 | 画面关系清楚时也可以无字幕 |
| 用户明确说明忘带枕头，现场用衣服垫着 | 枕头忘了带，外套先顶一晚 | 只在本期确有此事时写 |
| 画面只呈现煮水，没有个人经历 | 留白，保留烧水声 | 不补“等这一刻很久了”等经历 |

每句通常停留约 3–5 秒，随句长和画面调整，读完后留出无字画面。不要为了铺满所有段落增加字幕。`edit-notes.md` 的字幕表保留成片时间、文案作用及事实依据；参考作者的观察尺度与克制表达，另写自己的句子。

仅有可见动作、没有值得补充的信息时，整段乃至整片可以没有中文旁注。用户要求给字幕方案或示例，也可明确写“本段留白”及理由；字体样张用标明演示用途的文字，不把占位文字加入正式字幕表。精简文案后仍要保留声音与生活节奏。

## 新一期的变量

依据本期内容确定人数、季节、地点、装备、饮食、是否过夜、是否收营、画幅和时长。素材只覆盖部分生活过程时，围绕现有事件剪成完整的小篇章。

把稳定观察、动作因果、生活回报、稀疏文字、真实昼夜光线和情境化声音作为风格核心。用最终观看体验判断相似程度。
