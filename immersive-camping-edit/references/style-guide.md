# 风格与剪辑判断

## 观看目标

让观众与人物一起进入环境、安顿生活、感受使用和享用的时刻。保持旁观的距离和真实的生活速度，让动作、触感、空间与人物关系逐步被感知。

风格由以下关系共同建立：整体画面使人知道身在何处，细节让人感到正在做事，结果和使用使准备有意义，安静停留让人有时间体会。日记旁注带出这次选择与人物语气，连续原声让环境保持在场。

默认交付画幅为 4:3，中文旁注采用小号系统常规无衬线白字与贴字半透明黑底；这些是系列视觉规范。用户指定其他画幅或样式时按其要求执行，并保全动作和阅读空间。

每期依素材确定人数、季节、地点、设备、饮食、是否过夜和时长。围绕已拍到的小过程组织完整体验；阶段数量和镜头长度服从本期内容。

## 镜头语法

### 先确定镜头的作用

| 作用 | 观众获得什么 | 保留与退出的依据 |
| --- | --- | --- |
| 建立空间 | 人在哪里、物件如何分布、动作朝哪里发生 | 留到主体与关系可辨认，新的行动出现后推进 |
| 推进事件 | 状态如何改变、关键操作如何完成 | 保留理解变化所需的触发、执行与结果 |
| 呈现细节 | 手的用力、材质、声音与微小变化 | 留到该细节可感知，并接回所属事件 |
| 呈现结果与享用 | 准备带来了什么、人物如何使用它 | 给成品、使用或人物反应以辨认和感受时间 |
| 安静停留 | 空间、光线、环境声或关系本身的感受 | 允许持续观看；同类镜头重复时压缩，新的细微变化可延长 |

一个区间可兼有多个作用。切换景别只在空间、动作、细节或感受需要变化时发生；保持人物方位、运动方向和动作阶段可理解。

按源时间区间识别事件，检查全条素材中的主体入场、操作变化与结果。首段空景之后可能出现关键行动，先定位实际变化再选区间。为主要事件标出开始状态、关键执行和完成状态；相机连续拍到的过程可以在一个稳定镜头内成立。

先用整体交代人物和空间，再按需要靠近关键操作，回到完成状态或使用。缺少某个景别时使用已有画面讲清关系；减少无作用的切换。自然做事的手、背影、人与环境的比例和同伴互动都可承担叙事。

### 处理素材不足与冲突

稳定观察是选镜条件，连续检查方法见 [稳定性筛选](review.md#稳定性筛选与验收)。平顺且有目的的运镜可以保留；抖动优先通过替换、修剪或已验证的防抖处理，最终动作和构图都要成立。

当完整性与重复冲突时，保留新信息、关键变化和结果，压缩已被理解的重复操作。当漂亮画面与连贯性冲突时，找到它承担的空间或感受作用，再决定位置和长度。片长从这些选择中形成。

缺少事件结果时，先寻找同一事件的完成状态、后续使用或能接通的动作；信息足以理解时缩短该段，仍无法理解时合并或省略。缺少享用镜头时使用确实拍到的完成状态和环境停留，保持人物行为与时间关系真实。

## 节奏

### 决定入出点

进入时让观众知道要看什么，关键变化发生时保持动作可读，离开前给结果以辨认时间。快动作可能需要更完整地保留，重复慢动作可以省略；按内容调整，采用正常速度检查。

切点由下一镜增加的信息和当前镜头尚需完成的体验共同决定。结果刚出现就切走会使劳动没有落点；同一信息反复展示会使过程停滞。按事件复看，检查每次切换是否在观众能跟上的位置。

### 组织段落的呼吸

在关键操作段落集中注意力，在使用、互动与环境段落释放注意力。连续原声和无字画面为真实声音、动作及安静停留提供空间。舒缓来自有余地的观看，镜头仍应持续提供可理解或可感受的内容。

重复步骤可用有因果关系的省略或蒙太奇串联，保留重要操作的真实速度。音乐可以跨镜头连接一个段落；动作完整性优先于卡拍。

### 开场与结尾

先剪正文，再选择开场能建立的期待。直接进入环境和第一件事即可；预告用于提前呈现本期有区别的体验，回到正文后继续推进。片名与必要介绍融入实拍，按阅读与动作需要确定时长。

结尾放在本片已成立的状态。坐下享用、安静相处或完成离开都可收束，保留足以感受结束的画面和声音尾部。素材只覆盖半天时围绕半天的变化完成小篇章。

## 时段衔接

先建立前后事件关系，再选择直切、声音桥或短暂淡变。以空间、光线和生活动作交代时间变化。

| 变化 | 寻找的联系 | 素材有限时 |
| --- | --- | --- |
| 进入场景 | 环境、主体入场、停下和开始做事 | 从第一个可理解的真实动作进入 |
| 环境或光线改变 | 同地点或同物件保持联系，新的光线与行动接续 | 用已有新时段宽景重新定位，再进入活动 |
| 经过较长时间 | 前一活动收束，同地点重现，下一活动开始 | 保留真实时间跳跃，必要时加入有依据的简短时间信息 |

按素材实际覆盖的变化规划，保留昼夜差异和人物位置的可理解性。需要停顿时使用短暂淡变或黑场，正在发生的生活通常直接接续。

声音桥使用前后场景真实可用的录音，让观众先听见新空间或短暂延续上一段声底；连续听审后确定位置与长度。随附基础渲染器的逐段淡化只完成其声明的能力，J/L cut 需在实际支持的工具中实现。

在 `edit-notes.md` 用“前镜 → 联系线索 → 后镜”记录重要边界，连续复看两侧约 10–15 秒，检查动作、位置、光线与声音是否容易理解。

## 颜色和光线

以干净、清晰、自然为目标，保持白色中性、肤色自然、主体有层次。保留日照方向、傍晚暖意、夜间灯光与暗部关系，让不同时间仍呈现真实差别。

先做正确的色彩转换，再校正和匹配相邻镜头；原生参数与效果按 [逐镜头调色](color-grade.md) 执行。依据本期画面调节力度，先在目标引擎校准代表镜头，再逐镜应用。

## 实拍中的片头与信息介绍

建立跨期复用的介绍方式。固定系列名称、系统常规字体、文字层级、线条和入退节奏；本期片名、地点、信息量、出现镜头与版位随素材调整。让观众一边看到抵达和开始生活，一边获得必要信息。

默认先规划一组轻量系列/本期身份，地点明确时再安排地点信息。只选本片有用的模块；素材较短时可合为一组，已经有合适片头时延续已有设计。模板见 [presets.json](../assets/intro-kit/presets.json)，外观见 [实拍排版样张](../assets/intro-kit/preview.jpg)。模板只提供起始比例，按画面空位调整。

| 模块 | 何时有用 | 内容与实现 |
| --- | --- | --- |
| 系列与本期身份 | 车辆到达、第一段空间建立或稳定宽景 | 小号系列名配本期短标题，可用一条细线组织层级；实拍持续，标题避开车辆经过路径 |
| 地点与当次条件 | 观众已看懂抵达之后，或可识别环境的宽景 | 地点为主；已确认的日期、天气、温度可作为次信息。每组最多两行，未知项整项省略并收拢版式 |
| 物件旁信息 | 仪表、地图、装备或食物旁确有需要解释的细节 | 在物件旁空位给短说明，必要时用细引线指明对象；对象离开或换镜即退出 |

抵达、下车和取物时，用正文旁注逐步交代本期值得知道的地点、同行者与当次安排，让观众知道谁来到这里、准备怎样度过这一次。按实际内容选择，已由标题交代的信息可直接接着往下说；本次安排须有用户陈述或现场人声依据。它们沿用日记字幕样式，随动作展开，无需增加一套介绍卡，也不必在开头一次说完。

系列名来自用户已有身份；尚未确定时可用中性的“CAMPING DIARY”，不编造期号。地点使用用户确认的地域层级；天气与温度需要当次可靠记录，文件名、树影和画面亮暗不能推出准确日期或温度。历史天气、仪表读数与实测环境温度分别说明；读数若受车内或设备环境影响，保留该限制。装备名与规格也须有依据。

### 排版与动效

- 保持系统常规字重与正常字距。系列小字约 1.8–2.2% 画高，本期标题约 3.0–3.6%，地点/注释约 2.0–2.4%；这是 4:3 的起始比例，主标题也应让画面占主导。
- 开场文字通常先等画面建立约 1–2 秒，再轻淡入；整组显示约 4–7 秒，入/退约 0.3–0.5 秒。按动作、阅读量和镜头时长调整，具体落点写入当期计划。
- 默认只做透明度渐变。轻微上移可作为原创变化，位移约画高 0.5–1%，与进入同步，落定后保持。
- 使用单个稳定锚点和充分留白，起始安全边距约 7–9%。随画面选择左上、左中或另一处安静区域，检查全段人物、车辆和手的运动路径。细线只承担分隔或指向作用。
- 开场标题与地点信息优先使用透明底；背景过亮或繁杂时调整时机、位置，或用局部轻深底提升可读性。中文日记仍用既定半透明黑底，信息介绍有自己的层级。
- 同时只保留一个主要信息组；系列小签名可与一条必要旁注共存，前提是阅读与画面都清楚。不要把片名、地图、天气、装备名和日记堆在同一时刻。
- 介绍可在相邻镜头间持续，但须检查每一镜的留白与对比度；物件注释只在对应对象仍明确时存在。固定注释足够时直接使用；只有确需跟随运动才另做实际跟踪并验证，不能把屏幕固定字称作跟踪。

系列身份使用用户自己的名称与简单几何线条，保持跨期一致的信息层级和进出节奏。

### 当期计划与验收

在 `intro-plan.json` 记录所选模块、最终文案、事实来源、源素材/源区间、成片入出点、版位、每层 ID、动效意图及实现状态。把填好的图层写入 `timeline.overlays` 供配置预览；剪映里保留独立可编辑文字与独立线条/图形对象。模板中的占位文字和未填期号须在正式导出前清除。

先在本期实际画面制作约 12–20 秒样片，检查第一帧、入场中间、完全显示、跨镜处、退出和最后一帧。完整阅读所需时间、动作可见性、线条粗细与主体对比都要成立。文字应独立淡变，底片亮度、运动与原声按原剪辑继续；不为做标题让整段视频淡黑。预览和剪映的动画分别验收，原生动效未验证时如实记录，按 [介绍层交接](jianying-project.md#介绍层与动效交接) 处理。

## 字幕与文案

### 统一排版规格

中文日记正文固定为以下起始规格，先做实际画面样张再微调。查看 [自有素材排版样张](../assets/caption-layout-preview.jpg)，该图仅演示文字外观。

| 属性 | 默认目标 |
| --- | --- |
| 字体 | 系统中文无衬线的常规字重；同一期固定一个家族、一个正文字重 |
| 字体选择 | macOS 默认系统苹方简体常规（PingFang SC Regular）；其他系统使用本机默认中文无衬线常规，如微软雅黑或 Noto Sans CJK Regular。按实际字形检查并记录替代字体 |
| 字号 | 画面高度约 2.4%，1440×1080 时约 26 px；720×540 时约 13 px。高分辨率按比例放大 |
| 颜色与底色 | 白字，黑色底约 53% 不透明度；每行贴合字宽，横内边距约 0.35 字高、纵约 0.16 字高 |
| 位置 | 默认水平居中，黑底下沿距画面底部约 9% 高度；同一段落保持一致 |
| 行长 | 一行优先，通常 8–18 个中文字；最多两行，文字最大宽度约画面 72%。按完整意思改写或分时出现，保留必要的因果与个人语气 |
| 动效 | 默认静态出现和消失，必要时轻淡入淡出；保留平静观看节奏 |

不透明度 53% 等价于约 47% 透明度，按软件字段含义填写。原生剪映字号、背景宽高、坐标与像素的单位不同，须按 [原生文字样式](jianying-project.md#字幕样式补全) 用实际画面校准，不能照抄 26 作为所有软件的字号。渲染器规格与原生工程分别验收。

避开花体、衬线正文、粗描边、重阴影、彩色字、弹跳与打字机效果。英文信息标签用同一简洁无衬线体系、少量大写、白字透明底，字号约 2.8% 高度；只交代有证据的信息，通常一行。英文标题与中文旁注分工清楚，不每个时段都叠一套中英标题。

使用本机系统常规字体，保持正常字距与字形比例，按需替换为系统同类字体；固定记录实际家族、字重和字体路径。公共 Skill 不打包系统商业字体。新电脑须检查中文标点、拉丁字母及缺字，按最终画面测量大小与留白。正文既要克制，也须在目标观看尺寸可读。

字幕避让人物脸、手部操作、食物和器具结果。优先挪开字幕出现的时段、缩短文案，仍遮挡时将整组同场字幕移到另一处安静留白；保持安全区和统一对齐，不让每句话随机跳位置。随附渲染器仅支持 top/center/bottom，复杂避让在剪映独立文字对象中完成。全片交付前检查日间、手部、夜间、两行文字和首中末字幕。

### 有人在场的日记旁注

让观众跟上这次露营，也逐渐认识做事的人。语气朴素、亲近，围绕当次具体的人、物件和变化表达；保留自然的口语、偏好和轻微幽默。把普通动作写成宏大感悟、套用“逃离喧嚣、治愈一切、人间值得、奔赴热爱”等口号，会抹掉这一次的特点。

**事实有依据，并且对理解、人物或叙事至少有一种作用，句子就有保留价值。**

| 作用 | 值得交代的内容 |
| --- | --- |
| 理解 | 当次情境、选择理由、物件用途、过程中的小状况 |
| 人物 | 有依据的偏好、使用习惯、身体感受、伙伴互动与轻幽默 |
| 叙事 | 本次安排的铺垫、行动变化、阶段完成、下一步与前后呼应 |

画面中已经出现的动作和状态，也能承担阶段收束或人物表达。“桌子安顿好了，接着准备晚饭”可以连接搭建和做饭；逐个报告桌子、杯子、餐具都已摆好，则缺少推进。结合前后事件判断作用，保留能让观众跟上生活的句子。

个人经历、过去使用习惯、打算、心情及冷暖、味道等主观感受，来自用户陈述或可核实的现场人声。画面支持的当前行为、关系和变化可以写成自然观察；仅有蒸汽不能确认香味，添衣也不能独自证明本人觉得冷。轻幽默贴着可见行为，不替人物或动物编造内心独白。缺少某类依据时，使用有依据的表达或让该处留白。

### 按事件安排疏密

建立事件链时，先找本期值得交代的情境、人物与变化，再写候选句并删去赘述。开场让观众进入这一次，正文在选择、变化和阶段完成时接上人物的声音；重复操作、完整动作和安静享用可形成连续无字段落。按事件安排内容，不设每分钟句数或字幕总量，也不要求每个事件都配字。

按前后事件连接句意。自然的两句可构成一个小段落，中间按意思换气；一句可跨相邻镜头保持，按整段阅读检查。保留完整意思和人物语气，跨剪口连续显示同一句。

每句通常停留约 3–5 秒，长句和两句小段落按阅读量延长或分时出现。读完后留出无字观看空间，检查连着读是否疲劳，以及长段留白是否遗漏本次选择、关键变化或人物表达。先利用现有信息补足理解，再判断该处是否适合安静观看；用户明确要求纯观察时遵从其要求。

在 `edit-notes.md` 的字幕表保留成片入出点、文案、作用、事实依据与前后关系，并记录主要连续留白段落的作用。缺少某条依据时只处理相关内容，继续规划其他有价值的旁注。字体样张用标明演示用途的文字，占位文字不进入正式字幕表。
