# 成片复核与下一会话交接

## 复核方法

默认在剪映时间线内连续预览、听审和验收，审片 MP4 不属于默认交付。技术检查和内容判断分别记录；工程能打开保存，只支持相应技术结论，动作、节奏与声音需要实际观看和听审。视频导出检查仅在实际导出时执行。

先生成覆盖全片的时间线接触表，并实际查看每张。进一步检查所有章节边界、字幕出现/消失、变速段、相似机位切换、动作结果、片头和最后几秒。支持连续视频审看时以正常速度审看；仅有静态抽帧时记录其局限，按需加密切点两侧画面。稳定性须按下节连续检查，静态检查不能完成该项验收。

## 稳定性筛选与验收

稳定性检查分两次完成：选镜时检查完整拟用源区间和切点附近，工程预览时检查实际播放速度、裁切及相邻剪口。覆盖正文、预告和过渡中的每个视频片段。使用原片或保持连续时序的代理，按预定播放速度连续审看；稀疏抽帧拼成的图片序列不能证明稳定，正常速度仍可感知的细碎高频抖动也要处理。

用固定背景、地平线和画面边缘判断相机是否突然平移、旋转、颠簸或反复寻找构图。人物走动、手部操作、火焰和风吹树叶属于场景运动；平顺且有明确目的的摇移、跟拍可以保留。不要用整幅运动量或光流大小直接判废；运动轨迹分析只用于定位疑点，须检查对应连续画面。

按以下顺序处理已发现的不稳区间：

1. 换用能承担同一叙事作用的稳定镜头。
2. 调整源入出点，去掉碰机位、开拍或收机时的晃动，保留确实稳定且动作成立的子区间。避免为躲抖动截断关键动作。
3. 仍无合适区间时，缩短、合并或省略该过程。独有且重要的画面可尝试实际可用的防抖；防抖失败或残留明显晃动时放弃该画面。仅因独有、好看或需要凑时长，不能将其标为通过。

防抖先在该镜头短样片上验证。连续对照处理前后，检查主体漂移、边缘拉扯、果冻变形、黑边、裁切呼吸和运动模糊；按目标 4:3 或用户画幅确认手、工具和动作结果仍完整，检查音画及源时间映射。过度裁切或形变时改用替换、修剪或省略。慢放、转场、增加锐化或仅填写“防抖”配置均不能替代效果验证。

优先使用目标剪映实际可用的原生防抖，保持原片引用并验证工程画面和保存重开。处理后中间片可用于诊断；正式工程的原片与代理关系按 [原片区间约定](jianying-project.md#原片区间与调整余量) 验证，保留完整时长和调整余量。当前随附渲染器没有防抖字段，原生防抖批量写入也尚未验证，不得照搬调色材料模板声称已实现。

在 `shot-log.json` 用 `stability` 记录 `unreviewed`、`passed` 或 `rejected`；`motion_review` 记录实际检查的源区间、播放速度、方法、问题区间及处理结论。修剪或防抖后，以最终拟用区间重新检查再标 `passed`；修改速度或裁切后同样重查。该状态只对应已检查的源区间和处理版本，成片检查另记在 `review.md`。输出前核对每段实际源区间、速度、构图和防抖版本与检查记录一致，并记录其成片稳定性检查结果。保留被弃用区间和原因，便于替换与追溯。

正式交付选镜只纳入稳定性已通过的区间。用户明确要求保留的抖动镜头，记录其指令、位置和残留问题，保留问题状态。缺少连续审看能力时，继续完成素材整理和暂排，候选保持 `unreviewed`；交付暂排时须标为“待稳定性复核的暂排工程”，并在 `review.md` 列出未验证的成片/源区间。暂排不能计作稳定性验收完成，也不能写“画面已全面复核”。

## 声音复核

直接听审可用时，听取全片并检查剪口、突发声、底声跳变、音乐出入和对白。波形、响度、频谱和机器分类只能完成相应技术检查。没有直接听审就明确写“声音待人工听审”，交付待听审工程并给出时间线位置。

有配乐时按 [配乐与原声](audio/music-direction.md) 对照 cue 表，连续复核每个入出点两侧、完整乐句及停止后的一段原声。检查进入与退出是否服务当前事件，重要声音能否突出，原声区间是否有足够的停留；在剪映中另查独立音乐片段、音量与淡化，保存重开验证。方案、剪映写入和实际听审分别记录状态；视频导出状态仅在用户要求导出时记录。

## 内容检查

按本片实际事件检查开场、主要变化与收束，核对 [字幕规格](style-guide.md#字幕与文案)。检查完整源素材中的主体晚入场与后续动作，按区间判断作用；素材缺少的阶段据实省略。

| 项目 | 通过条件 | 发现问题后的动作 |
| --- | --- | --- |
| 事件 | 按源区间识别作用；到达等关键事件的起因和结果可读 | 查主体晚入场及被删动作，补整体/结果或合并、缩短 |
| 动作 | 关键执行与完成可读，前后顺序成立 | 调整源入出点或换候选镜头 |
| 稳定性 | 每个拟用区间已连续检查；无干扰观看的抖动，处理后构图与边缘自然 | 按稳定性筛选换镜、修剪、验证防抖或省略，并重查成片 |
| 景别与补录 | 同一事件的远中近特写互补，拍次间手势、方向与物件状态匹配，动作只推进一次 | 重选源区间，调整切点和景别，删去重复起势与完成 |
| 环境空镜 | 在操作间形成自然停留，同地点、时段与声音联系清楚，返回动作可理解 | 移至等待、休息或阶段完成处，按实际感受调整停留，压缩重复环境画面 |
| 节奏与衔接 | 开场自然进入；场景或时段变化有时间/空间依据；正文服从动作 | 重建前后事件关系，删无作用的标题卡和特效，恢复必要停留 |
| 情绪 | 生活和环境有存在感，结尾自然 | 补使用/享用画面，减少器材重复展示 |
| 真实性 | 地点、天气、经历和字幕有来源 | 删除或改写无证据的信息 |
| 画幅 | 手、工具、人物和结果没有关键裁切 | 重定位裁切、改contain或改输出画幅 |
| 色彩 | 色彩解释正确；韩系 Ins 的干净通透、柔和亮部与自然肤色成立，邻镜统一且保留昼夜差异 | 校正偏色、曝光与杂色，再按代表帧统一风格力度 |
| 文字内容 | 每句有依据，承担帮助理解、呈现人物或连接叙事中的至少一种作用 | 删口号、逐镜报动作和无来源的经历；可见状态承担阶段收束、转折或有依据的感受时保留 |
| 字幕安排 | 按本片已有素材和信息交代情境、选择、变化、阶段落点与人物表达；文字与无字区间有节奏 | 先查多余与缺失，按已有依据补交代或人物表达，再调时序和留白；按事件判断，不以固定句数验收 |
| 字幕外观 | 中文小号无衬线白字、贴字半透明黑底；安全区内最多两行，避开主体 | 按实际画幅校准字体、字号、黑底、位置及停留；检查剪映实际预览与保存重开 |
| 片头与介绍层 | 系列身份一致，有依据的地点、同行者与本次安排随动作自然交代；图层独立入退，跨镜仍可读 | 按依据补齐有用交代，个人安排核对用户陈述或现场人声；按 intro-plan 检查入退与剪口，挪位或删无用信息，清除占位内容 |
| 物件注释 | 有新增解释，明确对应当前对象，不留到无关镜头 | 缩短区间、重定位或省略；确需跟踪时实际验证 |
| 声音 | 动作可听，底声连续或有意分章，突发声受控 | 调整gain/声底/淡入淡出后听审 |

## 风格验收

在完整段落中检查以下关系；给每项结论记录成片位置和实际检查方式。

| 判断 | 通过条件 | 修订方向 |
| --- | --- | --- |
| 事件推进 | 能说清前后状态如何变化，主要动作的结果可读 | 恢复关键变化和结果，删去重复准备 |
| 镜头作用 | 每镜承担事件、空间、感官或情绪作用，安静停留有可感受的内容 | 合并同作用重复镜头，调整无目的的切换和停留 |
| 生活落点 | 重要准备之后有素材支持的完成、使用、享用或环境停留 | 寻找现有结果，按实际覆盖缩短或重组过程 |
| 注意力变化 | 操作可读，多景别与空镜让观看有紧有松，享用有余地，关键声音能被感知 | 调整剪口、空镜位置与音乐出入，保护连续原声和动作尾部 |
| 人物表达 | 日记旁注有依据，带出本次选择、关系或变化，完整动作有无字空间 | 补足已有信息中的有用交代，删掉重复报动作与泛泛感慨 |
| 素材适配 | 章节、镜头长度、音乐位置和片长均有本期依据 | 按实际事件重排，省略素材未覆盖的阶段 |

只用本 Skill 和本期素材解释这些选择。技术检查通过后，继续以连续观看与实际听审判断风格；尚未完成的检查保留待验状态。

## 素材库与原片可编辑性

按 [完整素材库](jianying-project.md#完整素材库) 对照整个用户目录的媒体清单核对导入。检查未用素材仍可搜索、预览和拖入，已用标识与时间线源区间相符，异常文件逐项有记录。验证操作在工程副本进行，完成后正式工程保留已定剪辑。

核对每个视频片段绑定完整原文件、完整源时长和正确源区间。按 [调整余量验证](jianying-project.md#原片区间与调整余量) 试调有前后余量的片段，确认能取得原选段之外的画面、原声保持同步；素材库和片段引用均须保存重开后复查。只验证播放或片段计数时，继续将可编辑性标为待验证。

## 技术检查

先检查工程分辨率、帧率、累计时长、离线素材、片段源区间与轨道对象；在剪映内播放首尾、剪口及关键段落，检查黑帧、冻结和截断。完整工程覆盖全片，保留独立原片片段、原声、音乐与字幕。打开、保存、退出并重开后记录实际检查结果。

以下文件检查仅在用户要求视频导出或实际生成短段技术测试文件时执行。用媒体检查脚本核对输出的时长、尺寸、帧率、视频/音频流。使用完整 FFmpeg 对成片解码到 null，检查退出码和错误日志。检查开头、拼接点和结尾有无意外黑帧、冻结或被截断的音画。

如需响度测量，使用 FFmpeg 的 `ebur128` / `astats` 等可用滤镜记录技术数据。区分样本峰值和真峰值；按用户发布需求设定目标，未指定时由听感决定适当调整。保持真实动态，避免逐镜独立强制拉到同一响度。

检查成片时间与时间线预计值在帧量化范围内一致。无意的累计漂移需要修复；记录每段实际长度与最终文件长度。

结构校验与小样成功只支持对应范围。工程操作、实际听审及按需导出的文件检查分别记录。

## 用户交接

剪片任务默认交付本机 Mac 剪映可编辑完整工程和备份，提供工程位置及待关注的时间线位置，用户直接在剪映内预览。完整素材与使用映射、`timeline.json`、`edit-notes.md`、`review.md` 和接触表保存在任务目录。用户明确要求视频导出、只分析或指定其他软件时，按其要求交接。输出位置遵守当前会话规则。

目标剪映不可用或完整工程验证未通过时，在 `review.md` 明确“工程未完成”、具体阻塞和待验证项，保留工程与工作文件，继续推进可完成部分。

时间线中保留源 ID、路径和入出点，交接记录包含版本、依赖与实际运行命令。若源路径是绝对路径，说明另一台机器需要重新映射；同一台机器的新会话可直接定位。相对路径按时间线文件位置解析，复制时间线时同步检查可解析性。

下一会话复核时，先读取最新保存工程、完整素材映射、时间线和 review.md，再针对用户反馈复核有关区间。将“源素材不足”“剪辑选择”“声音尚待听审”“导出问题”分开处理，修改时保留上一版本。

首次真实原始素材测试前，只能称本 Skill 已通过工具/结构检查。待实际成片与用户反馈后，再评价风格泛化是否成立。
