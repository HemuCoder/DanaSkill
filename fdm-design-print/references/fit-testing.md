# 配合设计与局部试打

## 先定义要验证的动作

用实物操作描述合格条件，例如螺钉能锁紧且孔底留有余量、滑块能走完全程、夹口能插入并保持。优先读取现有工程和试配反馈，再确定需要测量的尺寸。区分实测值、图纸标称值与估算值。关键尺寸待定时，把它保留为可调参数。

## 保留决定结果的条件

| 要验证的部位 | 设计与试样要点 |
| --- | --- |
| 塑料自攻螺钉 | 盖板开自由通孔，按头型留承压面或沉孔。承接件做一体加厚座和光滑底孔，按锁紧后的实际伸入长度留尖端余量。试样复现座壁厚、孔深、周边连接与打印方向，用实际螺钉检查穿过盖板、咬合和锁紧。 |
| 频繁拆装处 | 按预期拆装频次与项目约定选连接件。沿实际装配顺序检查整颗螺钉的进入与退出、批头对正、刀杆和手柄的转动空间。使用留置螺母时，一并检查放入、止转和拆卸路径。 |
| 孔槽、导轨和卡扣 | 保留定位基准、配合面的实际壁厚、导入段、弹性臂根部及装入方向。长导轨还要检查全行程的平直度与卡滞，局部截面样只能确认截面配合。只调目标尺寸，保持其他接口的位置、尺寸和已有孔补偿。 |
| 高薄边或易摆的凸起 | 保留实际打印朝向、最后一个稳定连接点至顶端的自由段高度，以及根部的支承方式。尖端随喷嘴摆动时优先缩短自由段或加可剪支撑筋。尖端稳定而新铺线卷起时，核对该高度的单层用时和冷却。 |

用与正式件相同的材料、计划喷嘴和相关工艺切片。同一块小样可以并排试几个底孔或配合间隙，每个候选只改变一个待比较的尺寸，记录它与实物结果的对应关系。比较冷却效果时，还要把小样和整盘在缺陷高度的单层用时对齐或说明差异。

## 记录实测范围

把版本、关键条件、实际完成的操作及结果一起记下。尺寸已测、切片已核对、实物已装入、反复拆装和承载各有独立结论。变更后对照尺寸、材料、方向和工艺，重验受影响的功能，保留仍适用的旧结果。

- 调整环形握持件内径时，保留夹口尺寸及位置基准。佩戴合适只确认手部配合。夹口插拔和保持力分别用配套件试验。
- 薄板样件的孔位已对正，成品增加了板厚。沿用已确认的孔中心距，用全厚试样复验弯钩能否穿过孔壁，再用全部安装点检查能否同时落座。
