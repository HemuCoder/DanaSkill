# H2C 与 Bambu Studio 配置

## 先读工程里的有效参数

在 Bambu Studio 核对打印机型号、启用的左右喷嘴及直径、打印板、耗材和工艺。已有 3MF 再查看盘和对象的覆盖设置。读取本机安装目录的系统预设 JSON 时，沿 `inherits` 到基础预设，再用子预设及工程覆盖值替换。单独一份 H2C 文件只包含部分参数。

例如，H2C、0.4 mm 喷嘴、0.20 mm Standard 的一份系统预设采用顶部 Z 距离 0.20 mm、顶部接触面 2 层、顶部接触面线距 0.50 mm、阈值角 30°。这些数值用于对照，生产配置取当前机器、材料和工程的有效值。

## 支撑接在哪里

- 大面积平顶可以用普通紧贴支撑连续托住。交叠直线可改善底面，也可能增加剥离难度。手办等零散、曲面的悬垂可用有机树减少接触。能稳定桥接的跨度可在切片中确认两端落点，结合材料与相同跨度的试打判断。
- 自动支撑的阈值角按悬垂面相对水平面的坡度计算。由 30° 降到 25° 时，自动支撑通常会减少。“仅在打印板生成”限制支撑的起点。逐层看独立悬空的第一段有无托住、凹腔里的支撑能否完整退出，需要时调整方向、生成范围或局部涂绘。
- 检查排盘包络时计入实际使用的喷嘴范围、裙边和启用的擦料塔。多料工程还要在切片预览核对支撑主体、接触面和模型本体使用的耗材。

## 按症状调单料支撑

| 试打现象 | 怎么判断和验证 |
| --- | --- |
| 支撑粘牢，撕走了悬空底面的一层 | 找到被撕开的界面，先看顶部 Z 距离。保持方向和接触面配置，在同料小样上单独增大间隙，比较剥离力度和底面垂线。 |
| 支撑好拆，底面垂线明显 | 在预览中看接触面有没有连续托底。覆盖不足先改覆盖。覆盖充分时，可固定间隙增加顶部接触面层数，或固定层数单独缩小间隙。0.20 mm 层高下可试 0.18 或 0.16 mm。同时改为 4 层的演示只说明一种组合。 |
| 侧壁擦伤、槽里的支撑卡住 | 检查支撑与侧壁的 XY 间距、支撑起点和整块退出的路径。转动模型或局部屏蔽，把接点移到隐藏面并给剪钳留空间。底部 Z 距离管支撑从模型表面长出处的竖向间隙。 |
| 薄边离开主体后出现波纹 | 观察喷嘴经过尖端时的动作。尖端随喷嘴摆动，先缩短自由段或加侧向连接。尖端稳定而新线卷起，检查该高度的单层用时、悬垂冷却是否触发、风扇是否运转和小层降速。试样保持根部连接和自由高度。 |

顶部接触面层数决定托底厚度，接触面线距决定线与线间的空隙，顶部 Z 距离决定支撑上表面到模型底面的间隙。改变顶部 Z 距离后重新切片，比较接触处实际的模型与支撑层高程。层高同步等设置可能使相近的输入值产生相同的实际间隙。冷却优先查看对应材料预设与实际触发条件。

## 用另一种耗材做接触面

当平底表面质量和易拆性都重要时，可选与模型材料匹配的专用支撑丝。拓竹也给出了 PLA Basic 与 PETG HF 或 PETG Basic 互撑的适用条件。通常模型和支撑主体用模型料，只将另一种料指派给“支撑/筏层界面”。H2C 可将两种材料分别映射到同直径的左右喷嘴，以实际装料和切片结果为准。

对照官方 PLA Basic 模型配 PETG HF 接触面的样例，顶部 Z 距离 0 mm、顶部接触面线距 0 mm 可作为小样起点。两项分别表示界面紧贴模型、界面铺满。先确认打印时界面留在原位、成形后可剥离且底面合格，再用于正式件。同料 PLA 采用有间隙的基线。换材料组合后重新验证。

参数定义、材料组合与 H2C 分配方法见[支撑设置](https://wiki.bambulab.com/zh/software/bambu-studio/support)、[PLA 与 PETG 互撑指南](https://wiki.bambulab.com/zh/filament-acc/filament/h2d-pla-and-petg-mutual-support)和[H2C 操作指南](https://wiki.bambulab.com/zh/h2c/manual/bambu-studio-h2c-operation)。
