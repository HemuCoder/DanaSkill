# FDM 零件设计与打印配置

按用户要完成的事选入口。设计新件时把打印方向和装配路径带进 CAD。给已有模型配盘时先保留原几何。处理试打反馈时，从缺陷的位置和出现时刻提出一个能区分成因的小样或观察方法。只做分析的请求，在给出判断依据后即可结束。

先读当前工作区和零件项目的规则，查已有设计源、实测记录及正在使用的工程。用户指定的材料、五金、打印机和交付形式直接沿用。尺寸缺失时，先找可用测量基准。会决定适配且现有资料无法推断的尺寸，说明量哪里、从哪个面量。估算值留在可调参数中，标明待实测。

## 设计与分件

- 找出外观面、支承面、配合面和主要受力方向。先走一遍装入、取出、锁紧和维修的顺序，再定壁、孔、卡扣和让位。改一处尺寸时保留已试配的独立接口。
- 大件先在装配外形上选接缝，顺着转角、折线、台阶或零件边界分件，尽量保留完整的可见大平面。再用实际启用的喷嘴可打印范围核对各件及裙边，从装配方向检查定位与固定。
- 外壳固定可采用盖板自由通孔、头部承压面与底壳一体的自攻螺丝座。项目规定塑料自攻连接时沿用该方案。按实物螺钉、材料、载荷、拆装频率和工具路径确定尺寸。螺丝座、导轨、卡扣或孔的试配，读[配合与小样](references/fit-testing.md)。
- 选打印朝向时同时看层纹相对载荷的方向、贴床面积、关键面精度、悬垂底面和拆支撑空间。高薄边沿打印方向量到最后一处与稳定主体相连的根部。优先缩短这段自由高度。必须竖打时，可在工具够得到的隐藏面增加可剪连接筋。

## 切片与试打

1. 打开目标机器、喷嘴、板材、耗材和工艺预设。已有工程以实际保存的盘级、对象级设置为起点。结合薄壁与受力选择墙数、填充和层高，按附着需要选裙边。切片预览中检查薄壁或细扣是否形成预期的挤出线。
2. 优先用摆放让支撑落在内侧、隐藏面且能取出的位置，避开外观面、滑动面和精密配合面。大平面与分散小悬垂分别评估普通紧贴支撑和树状支撑。成形可靠、拆后表面质量相当时再选省料方案。按需逐面强制、屏蔽或逐盘关闭支撑。
3. 遇到难拆、下垂、侧壁伤痕、薄边波纹或异料接触面，读[H2C 与 Bambu Studio 配置](references/h2c-bambu.md)。需要实物验证时，保留导致问题的几何与工况，优先比较一个变量，用观察结果决定下一步。
4. 报告写清证据覆盖的版本和功能。例如“已排除装配干涉”“已在切片中看到托底”“已实物试配滑动”。使用条件改变时，重验受影响的功能。项目指定的试装范围随结果一并说明。

## 打印交付

- 同一产品的一次 Bambu Studio 交付使用一个工程，多盘按试装和打印先后排好。逐盘保存对象与摆放、喷嘴及耗材映射、层高、墙数、裙边和支撑设置。关键接触区域在切片中核对实际路径和拆除空间。
- 依据项目规则归档设计源、预览、小样和打印文件。工作区实行编码交付时，按该项目规定的编码长度、字符、内部命名和本地映射位置执行，连同压缩包成员、3MF 标题、盘名、对象和部件名、导出任务名、源路径、STL 头和交付链接一起核对。保留真实机器及耗材配置。
- 复开最终交付路径下的 3MF，逐盘核对几何、单位、位置、配置和局部支撑标记。合盘、重命名或打包时，与变换前对照网格、盘内摆放、工艺参数及已有机器指令。交付时写明用户应先打哪盘、已验证什么，以及工程是否仍需在 Bambu Studio 切片。自动支撑路径以切片预览为准。
