## 沉浸式露营剪辑

[immersive-camping-edit](immersive-camping-edit/SKILL.md) 将本地露营素材剪成 LI300 参考风格的沉浸式露营日记，包含剪辑、配乐、字幕、逐镜调色与复核流程。

- 默认交付 Mac 剪映可编辑工程与审片视频。
- 逐段连续检查镜头稳定性，优先替换抖动镜头或截取稳定区间，防抖后复核构图与实际效果。
- 颜色方向为韩系 Ins 干净、清晰、简约、自然，按实际光线逐镜调整。
- 支持将原生颜色参数写在各视频片段自身的「调整」中；本机剪映 11.6 已验证九项参数及保存重开。
- 随附素材检查、接触表和配置渲染脚本，以及必要参考图片。

当前 v6 颜色参考仍待用户审核，不能将本期数值作为其他素材的固定预设。人工修改后的编码草稿回读仍需单独验证，后续调色须取得最新工程内容。

完整规则、工具用法及验证边界见 [Skill 文档](immersive-camping-edit/SKILL.md) 及其引用文件。
