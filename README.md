## 沉浸式露营剪辑

[immersive-camping-edit](immersive-camping-edit/SKILL.md) 将本地露营素材剪成有真实动作、现场感和自然日记旁注的生活影像。新会话依据 Skill 与本期素材即可开始工作。

- 按事件变化选镜，保留关键动作与完成后的生活落点。
- 根据观看需要决定停留和剪点，按声音价值安排配乐进入、退出与连续原声。
- 以具体、有人物在场的中文旁注串联情境、选择和变化，保留动作与环境自行展开的空间。
- 默认 4:3、小号常规无衬线白字与贴字半透明黑底，片头和信息层融入实拍。
- 逐镜校准曝光、白平衡与色彩，默认交付 Mac 剪映可编辑工程和审片 MP4。

使用入口见 [Skill](immersive-camping-edit/SKILL.md)，剪辑判断见 [风格规则](immersive-camping-edit/references/style-guide.md)。声音、调色、工程和验收文档按任务加载；随附脚本与介绍模板支持实际制作。

原生调色已有部分写入与保存重开证据，人工改稿后的编码工程回读仍需单独验证。当前能力范围见 [调色文档](immersive-camping-edit/references/color-grade.md#本机验证边界)。
