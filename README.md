## 沉浸式露营剪辑

[immersive-camping-edit](immersive-camping-edit/SKILL.md) 将本地露营素材剪成有真实动作、现场感和自然日记旁注的生活影像。新会话依据 Skill 与本期素材即可开始工作。

- 先把用户文件夹内全部可用媒体导入剪映素材库，保留未用素材与使用状态供人工补剪。
- 高光、简介底片、正文与空镜视频统一放在剪映主轨道，引用完整原片的选定区间，保留前后调整余量。
- 归组重复补录，用远、中、近、特写和匹配动作丰富画面，穿插有联系的环境空镜，让操作与停留有呼吸。
- 片头固定为高光剪辑，独立文字 `IN THIS EPISODE...` 在高光全段水平、垂直居中，随后用中英简介交代主题与营地，按本期需要展示天气；必要信息缺失时集中询问。
- 以具体、有人物在场的中文旁注串联情境、选择和变化，保留动作与环境自行展开的空间，按声音价值安排配乐进入、退出与连续原声。
- 默认 4:3。片头简介使用 Montserrat，正文使用系统字体；字号、缩放和黑底按 [文字规格](immersive-camping-edit/references/style-guide.md#统一文字规格) 设置，全部文案仅渐显 0.8 秒、渐隐 0.5 秒。
- 调色时逐镜形成韩系 Ins 简约、干净、通透的色彩，保留自然肤色和昼夜光线差异。
- 默认交付 Mac 剪映可编辑工程，在剪映内预览；MP4 仅在明确要求视频导出时提供。

使用入口见 [Skill](immersive-camping-edit/SKILL.md)，剪辑判断见 [风格规则](immersive-camping-edit/references/style-guide.md)。声音、调色、工程和验收文档按任务加载；随附脚本与介绍模板支持实际制作。

主轨道、片头文字和样式规格按目标剪映实际操作、面板读回及保存重开验收。原生调色已有部分写入与保存重开证据，人工改稿后的编码工程回读仍需单独验证。当前能力范围见 [调色文档](immersive-camping-edit/references/color-grade.md#本机验证边界)。
